# Focusly for macOS

**Your day in the notch.** Downloads for [Focusly](https://focusly.sh).

**[Download the latest version (DMG)](https://github.com/igorvieira/focusly-releases/releases/latest/download/Focusly-latest-macOS.dmg)** · requires macOS 14 or later

This repository only hosts release files. For purchases, licenses, or help, visit [focusly.sh/support](https://focusly.sh/support).
